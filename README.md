# Drag-N-Drop-App

This project demonstrates a basic drag-and-drop functionality using Vanilla JavaScript and the HTML5 Drag and Drop API. It allows users to drag elements from one container and drop them into another container smoothly.

<h1>🚀 Features</h1>

Drag items from one box and drop them into another

Uses native HTML5 drag & drop events

Prevents invalid drop actions

Clean and minimal JavaScript logic

Beginner-friendly implementation

<h1>🛠️ Technologies Used</h1>

HTML5

CSS3

JavaScript (ES6)
